# ePorcha — Vercel ফ্রি ডেপ্লয় গাইড

এই প্যাকেজ দিয়ে আপনার ePorcha সাইটটা **একদম ফ্রিতে** (Vercel Hobby প্ল্যান, কার্ড লাগে না) লাইভ করা যাবে — লাইভ API + খতিয়ান PDF ডাউনলোডসহ।

## কেন সার্ভার (proxy) লাগে?

`eporcha.tech`-এর API ব্রাউজারকে সরাসরি কল করতে দেয় না (CORS হেডার নেই)। তাই এই প্যাকেজের `api/` ফোল্ডারের ছোট ফাংশনগুলো সার্ভার থেকে API-তে কল করে আপনার সাইটে ডাটা এনে দেয়। আপনার ব্রাউজার শুধু আপনার নিজের সাইট (`/api/...`) -এর সাথে কথা বলে।

## যা যা আছে

| ফাইল | কাজ |
|---|---|
| `index.html` | পুরো সাইট — হিরো, ৭ সেবা কার্ড, বিভাগ → জেলা → উপজেলা → জরিপ → মৌজা খোঁজা, খতিয়ান টেবিল, প্রিভিউ, PDF ডাউনলোড, মৌজা ম্যাপ, FAQ, নির্দেশিকা, ফুটার |
| `api/dlrms.js` | বিভাগ/জেলা/উপজেলা/জরিপ/মৌজা/খতিয়ান তালিকার প্রক্সি |
| `api/khatian-record.js` | একটা খতিয়ানের বিস্তারিত |
| `api/mouza-map-browse.js`, `api/mouza-map-file.js` | মৌজা ম্যাপ (Google Drive ফোল্ডার) |
| `api/namjari-form.js`, `api/namjari-pdf.js` | প্রিন্ট ফর্ম (HTML) ও আসল PDF ডাউনলোড |
| `vercel.json`, `package.json` | Vercel সেটিংস (কোনো ডিপেন্ডেন্সি নেই) |

## ধাপ ১ — GitHub-এ আপলোড করুন (ফোন থেকেই হবে)

1. ফোনের ব্রাউজারে যান: **github.com** → Gmail দিয়ে ফ্রি অ্যাকাউন্ট খুলুন / লগইন করুন।
2. উপরে **+** → **New repository** → নাম দিন `eporcha` → **Create repository**।
3. **uploading an existing file**-এ ট্যাপ করুন → এই ZIP-এর ভেতরের সব ফাইল সিলেক্ট করে আপলোড করুন (ZIP ফাইলটা না, ভেতরের ফাইলগুলো) → **Commit changes**।

## ধাপ ২ — Vercel-এ ডেপ্লয় করুন (ফ্রি, কার্ড লাগে না)

1. ফোনের ব্রাউজারে যান: **vercel.com** → **Sign Up** → **Continue with GitHub** (GitHub-এর অনুমতি দিন)।
2. ড্যাশবোর্ডে **Add New… → Project** → আপনার `eporcha` রিপোজিটরি খুঁজে **Import** চাপুন।
3. কিছু বদলাতে হবে না — **Deploy** চাপুন। ১–২ মিনিট অপেক্ষা করুন।
4. হয়ে গেলে লিংক পাবেন, যেমন: `https://eporcha-xxx.vercel.app` — এটাই আপনার লাইভ সাইট। কাউকে পাঠালেই খুলবে।

## ধাপ ৩ — পরীক্ষা করুন

লিংক খুলে এটা চেক করুন: **ঢাকা → ঢাকা → সাভার → আর এস → ১৬৭ সাভার** — মোট **৫৮৯টি খতিয়ান** আসা উচিত, ১ নম্বরে "বাংলাদেশ সরকার পক্ষে ডেপুটি কমিশনার ঢাকা", মোট জমি 15.0517 একর। কোনো খতিয়ানে **PDF** বোতাম চাপলে আসল PDF নামবে (ফাইলনাম যেমন `khatian-rs-JL167-No1.pdf`)।

## ধাপ ৪ — (ঐচ্ছিক) Blogger-এ বসানো

Blogger → Pages → New page → HTML ভিউতে এই কোড বসান (লিংকটা আপনার Vercel লিংক দিয়ে বদলে নিন):

```html
<iframe src="https://আপনার-সাইট.vercel.app" style="width:100%;height:1500px;border:0;" loading="lazy" title="ePorcha - খতিয়ান অনুসন্ধান"></iframe>
```

## সমস্যা হলে

- **Deploy ফেল করলে:** Vercel-এর লগে দেখুন — সাধারণত GitHub-এ `api/` ফোল্ডার আপলোড না হলে হয়। সব ফাইল আছে কি না চেক করুন।
- **খতিয়ান আসছে না:** `https://eporcha.tech/api/dlrms/divisions?ROW_STATUS=1` ব্রাউজারে খুলে দেখুন — ওটা না খুললে মূল API-ই ডাউন আছে।
- **PDF মাঝে মাঝে 502 দেয়:** মূল PDF সার্ভার পরপর কলে মাঝে মাঝে 502 দেয় — এই প্যাকেজে একবার রিট্রাই দেওয়া আছে। না হলে কয়েক সেকেন্ড পরে আবার চাপুন, অথবা প্রিন্ট ফর্ম (HTML) দিয়ে প্রিন্ট → Save as PDF করুন।
- **পুরো মৌজার খতিয়ান বই:** একক খতিয়ানের PDF আসল PDF; পুরো মৌজার বই প্রিন্টযোগ্য HTML আকারে নামে — ব্রাউজারে খুলে Print → Save as PDF করুন।
